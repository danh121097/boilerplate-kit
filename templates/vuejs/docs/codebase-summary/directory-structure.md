# Directory Structure

The real `src/` tree, one line of purpose per folder and key file. Tests live in
`src/__tests__/`.

```text
src/
├── main.ts                      App entry: initServices() → registerPlugins() → mount
├── App.vue                      Root layout: nav + <RouterView> + locale toggle
├── components/
│   └── ui/                      Auto-registered UI primitives (only this dir)
│       ├── Button.vue           CVA-styled button
│       ├── Input.vue            Base input (floating label, mask, clearable)
│       ├── VeeInput.vue         vee-validate wrapper around <Input>
│       ├── Badge.vue            Status badge
│       ├── Card.vue             Simple card container
│       ├── badge.variants.ts    CVA variant map for Badge
│       └── input.props.ts       Shared BaseInputProps for Input + VeeInput
├── composables/
│   └── useSocketIO.ts           Socket.IO connection + useIo()/useSocketEvent()
├── directives/
│   ├── index.ts                 Barrel: re-exports vTrack
│   └── v-track.ts               Demo v-track click-tracking directive
├── enums/
│   ├── index.ts                 Barrel
│   ├── socket-events.ts         SOCKET_EVENT registry + unauthorized message
│   └── storage-keys.ts          STORAGE_KEYS (app-prefixed localStorage keys)
├── i18n/
│   └── locales/                 en.ts, ja.ts message catalogs
├── plugins/
│   ├── index.ts                 registerPlugins(app) — installs all of below
│   ├── i18n.ts                  vue-i18n instance + setLocale()
│   ├── pinia.ts                 createPinia() instance
│   ├── vue-query.ts             QueryClient + VueQueryPlugin setup
│   └── directives.ts            Registers app.directive("track", ...)
├── router/
│   └── index.ts                 vue-router with lazy public routes
├── scss/
│   ├── tailwind.css             Tailwind v4 entry + theme tokens
│   └── main.scss                Global resets, safe-area vars, body styles
├── services/
│   ├── index.ts                 Barrel: core + auth + users + init-services
│   ├── init-services.ts         Registers backends, base URLs, interceptors
│   ├── core/                    HTTP engine (see services-and-stores.md)
│   ├── auth/                    Auth model + mutations/queries + types
│   └── users/                   Users model + query + types
├── stores/
│   ├── counter.ts               Demo Pinia store
│   └── socket-io.ts             Holds the live Socket instance + auth flag
├── utils/
│   ├── index.ts                 Barrel
│   ├── cn.ts                    clsx + tailwind-merge class combiner
│   └── date-format.ts           dayjs formatDate() + fromNow()
└── views/
    ├── home-view.vue            Landing page
    ├── counter-view.vue         Demos the counter store
    ├── users-view.vue           Demos a TanStack query
    └── form-view.vue            Demos vee-validate + zod form
```

## Notes

- `auto-imports.d.ts` and `components.d.ts` (repo root) are generated by the
  unplugin tooling in `vite.config.ts` — do not edit by hand.
- Auto-imports cover `vue`, `vue-router`, `@vueuse/core`, `vue-i18n`, `pinia`,
  plus `src/composables/**` and `src/utils/**` (see `vite.config.ts`). Stores
  are deliberately NOT auto-imported.
