# CLAUDE.md

Guidance for Claude Code (and other coding agents) working in this repository.

## Project Overview

Expo (managed) + React Native mobile starter — Expo Router (file-based routes),
NativeWind v4, TanStack React Query, Zustand, an axios service layer with JWT
bearer + `expo-secure-store` refresh-token rotation + HMAC-signed requests,
react-i18next (en/ja). Package manager: **pnpm**.

- Handle edge cases and errors; keep public contracts stable unless intentional.

## Conventions Quick Reference

- **Filenames**: kebab-case for `.ts`/`.tsx`; hooks use `useXxx.ts` camelCase.
- **Imports**: always the `@/` alias (maps to `src/*`) — never relative `../`.
- **Routes**: file-based under `app/`; typed routes are generated by Expo Router.
- **Stores**: explicit `import { useXStore } from "@/stores/x"` (no auto-import).
- **Styling**: NativeWind `className` props; avoid inline `StyleSheet` where a class fits.
- **Token storage**: async only — `expo-secure-store` reads/writes return promises.
- **File size**: aim ≤ ~200 LOC; split early. Barrel `index.ts` per module.
- **Commits**: Conventional Commits (`feat`, `fix`, `refactor`, …). Do not auto-commit unless asked.

Full standards: [docs/code-standards.md](./docs/code-standards.md).

```bash
pnpm test         # jest-expo
pnpm lint         # eslint
pnpm format       # prettier --write
```
