# Project Overview — PDR

## Vision

A production-ready React 19 + TypeScript SPA starter that teams can scaffold once
and extend. Ships with a full axios service layer (JWT bearer + refresh-token
rotation + HMAC-signed requests), TanStack Router, TanStack React
Query, Zustand, shadcn/ui + Tailwind v4, react-i18next, and a complete Vitest
suite.

## Stack

| Concern | Choice | Version |
|---------|--------|---------|
| UI framework | React | 19 |
| Build tool | Vite | 8 |
| Router | TanStack Router (file-based) | 1.x |
| Data fetching | TanStack React Query | 5.x |
| State | Zustand | 5 |
| Forms | react-hook-form + zod | 7.x / 4.x |
| UI primitives | shadcn/ui (Radix) | new-york style |
| Styling | Tailwind CSS | v4 |
| HTTP | axios | 1.x |
| i18n | react-i18next + i18next | 15.x / 24.x |
| Tests | Vitest | 4.x |
| Package manager | pnpm | 9+ |
| Language | TypeScript | 6.x strict |

## Scripts

```bash
pnpm dev          # Vite dev server
pnpm build        # tsc -b + vite build
pnpm typecheck    # tsc -b
pnpm test         # vitest run (node env)
pnpm test:watch   # vitest watch
pnpm lint         # eslint (flat config, jiti) + prettier --check, read-only
pnpm lint:fix     # eslint --fix + prettier --write
pnpm format       # prettier --write
```

## Constraints

- No `any` without explicit justification comment.
- `strict: true` + `noUncheckedIndexedAccess: true` in tsconfig.
- `routeTree.gen.ts` + `auto-imports.d.ts` are committed cold-typecheck stubs — regenerated by the Vite plugins on every dev/build.
- HMAC secret is required by the bundled backends and must equal the backend `HMAC_SECRET`;
  it is an anti-abuse layer, not a security boundary (see `security-auth.md`).
- Access and refresh tokens in localStorage; the refresh token is sent in the request body.
- File size target ≤ 200 LOC per file; split early.
