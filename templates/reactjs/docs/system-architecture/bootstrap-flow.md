# Bootstrap Flow

```
index.html
  └── src/main.tsx
        1. initServices()          ← sets axios baseURLs + installs interceptors
        2. initI18n()              ← reads STORAGE_KEYS.LANGUAGE, inits i18next
        3. createRoot(#root).render(
             <StrictMode>
               <AppQueryClientProvider>   ← shared QueryClient
                 <I18nextProvider>        ← i18n context
                   <RouterProvider>       ← TanStack Router (context: queryClient)
                     <RootLayout>         ← __root.tsx nav + locale toggle
                       <Outlet />         ← matched route component
                     </RootLayout>
                   </RouterProvider>
                 </I18nextProvider>
               </AppQueryClientProvider>
             </StrictMode>
           )
```

## Key constraints

- `initServices()` must run before any `Api` instance makes a request, because it
  calls `Api.setBaseURL()` and `Api.registerInterceptors()`.
- `initI18n()` must run before `<I18nextProvider>` mounts to avoid a flash of
  untranslated keys.
- `routeTree.gen.ts` is auto-generated by the `@tanstack/router-plugin/vite` Vite
  plugin from the file-based routes in `src/routes/`. It is gitignored and
  regenerated on every `pnpm dev` / `pnpm build`.
