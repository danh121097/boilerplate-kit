# React + TypeScript Standards

## TypeScript config

- `strict: true` — all strict checks enabled.
- `noUncheckedIndexedAccess: true` — array/object index access returns `T | undefined`.
- No `any` without an explicit justification comment.
- Module resolution: `Bundler` (Vite-compatible).

## Component structure

```tsx
// 1. imports — named value, then type, then default, then side-effect
import { useState } from "react";
import type { HTMLAttributes } from "react";

// 2. interface/type declarations above the component
interface Props extends HTMLAttributes<HTMLDivElement> {
  label: string;
  error?: string;
}

// 3. named export (no default export for components)
export function MyComponent({ label, error, ...props }: Props) {
  // 4. hooks first
  const [open, setOpen] = useState(false);

  // 5. derived values
  const hasError = Boolean(error);

  // 6. handlers
  function handleClick() { setOpen((v) => !v); }

  // 7. render
  return <div {...props}>{label}</div>;
}
```

## forwardRef pattern

Use for all UI primitives (Button, Input, FormField) so react-hook-form and
other form libraries can attach refs:

```tsx
export const Input = forwardRef<HTMLInputElement, InputProps>(
  ({ className, ...props }, ref) => <input ref={ref} className={cn("...", className)} {...props} />,
);
Input.displayName = "Input";
```

## Hooks

- Custom hooks live in `src/hooks/` with `useXxx.ts` naming.
- Service query/mutation hooks are generated by `defineQuery`/`defineMutation`
  in the service layer — do not duplicate them in `src/hooks/`.

## Service queries in components

```tsx
// Route component — TanStack Query hook from service layer
const { data, isLoading, error } = useUsersListQuery();
```

## Stores

```tsx
// Explicit import — never rely on global/auto-import
import { useCounterStore } from "@/stores/counter";
const { count, increment } = useCounterStore();
```

## i18n

```tsx
const { t, i18n } = useTranslation();
// interpolation uses double-braces: t("users.error", { message: "..." })
```

## File size

Target ≤ 200 LOC per file. Split early by extracting:
- Variant/style definitions to a separate `-variants.ts`
- Business logic to a service or hook
- Sub-components to their own file
