# Project Overview — PDR

## Vision

A production-ready SSR-first React 19 + TypeScript starter (TanStack Start) that teams can scaffold once
and extend. Ships with a full axios service layer (httpOnly JWT cookies +
refresh-token rotation + HMAC-signed requests), TanStack Router, TanStack React
Query, Zustand, shadcn/ui + Tailwind v4, react-i18next, and a complete Vitest
suite.

## Scripts

```bash
pnpm dev          # Vite dev server
pnpm build        # tsc --noEmit + vite build
pnpm typecheck    # tsc --noEmit
pnpm test         # vitest run (node env)
pnpm test:watch   # vitest watch
pnpm lint         # eslint + prettier --check (read-only)
pnpm lint:fix     # eslint --fix + prettier --write
pnpm format       # prettier --write
```

## Constraints

- No `any` without explicit justification comment.
- `strict: true` + `noUncheckedIndexedAccess: true` in tsconfig.
- `routeTree.gen.ts` + `auto-imports.d.ts` are committed cold-typecheck stubs — regenerated by the Vite plugins on every dev/build.
- HMAC secret is required by the bundled backends and must equal backend `HMAC_SECRET`; empty means every request is rejected.
- Both tokens live in httpOnly cookies (server-managed); the client keeps only a readable session hint. The backend also returns the tokens in the JSON body, which the client ignores (accepted risk, see [security-auth](./system-architecture/security-auth.md#tokens-in-the-response-body)).
- File size target ≤ 200 LOC per file; split early.
