# TanStack Start Starter

> **SSR-first** React starter. For a **SPA-first** React starter (Vite only, no SSR), see the `reactjs` template instead.

A production-ready TanStack Start v1 template with full-stack TypeScript, SSR,
and a battle-tested client service layer.

## Stack

| Concern | Choice |
|---|---|
| Framework | **TanStack Start v1** (Vinxi / Nitro SSR) |
| Router | **TanStack Router** (file-based, built into Start) |
| Data fetching | **TanStack React Query** (built into Start) |
| State | **Zustand** |
| Forms | **react-hook-form + zod** |
| UI | **shadcn/ui + Tailwind v4** |
| HTTP | **axios** + JWT Bearer + httpOnly refresh cookie + HMAC |
| i18n | **react-i18next** (en / ja, persisted to localStorage) |
| Tests | **vitest** (node env, SSR-null cases included) |
| Package manager | **pnpm** |

## Routes

| Path | Description |
|---|---|
| `/` | Home — locale toggle + UI showcase |
| `/counter` | Zustand counter (client-only state) |
| `/users` | TanStack Query list, seeded by SSR loader + `createServerFn` |
| `/form` | react-hook-form + zod validation |

## Quick Start

```bash
pnpm install
cp .env.example .env   # fill in VITE_APP_ENDPOINT etc.
pnpm dev               # SSR dev server on http://localhost:3000
```

## SSR vs SPA

| | TanStack Start (this template) | reactjs template |
|---|---|---|
| Rendering | SSR + client hydration | SPA (client-only) |
| Entry points | `src/client.tsx` + `src/ssr.tsx` | `src/main.tsx` |
| Config | `app.config.ts` (Vinxi) | `vite.config.ts` |
| Server functions | `createServerFn` in `src/server/` | n/a |
| Service layer | Client-only (SSR-guarded) | Client-only |

## Service Layer

The axios service layer (`src/services/`) is **client-only**. All localStorage
accesses are guarded by `typeof window !== "undefined"` — on the server they
return `null` / no-op. Server functions in `src/server/` fetch data directly
without the client token registry.

## Environment Variables

```
VITE_APP_NAME=          # prefix for localStorage keys
VITE_APP_ENDPOINT=http://localhost:3000  # backend origin (REST base = origin + /api/v1; Socket.IO uses it bare)
VITE_API_PREFIX=/api/v1
VITE_LANGUAGE_CODE=en   # default locale
VITE_HMAC_SECRET=       # HMAC signing secret (must match backend)
VITE_BUILD_VERSION=     # injected by CI for x-version header
```
